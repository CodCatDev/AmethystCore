Minecraft Java Edition server implementation in Nim.

## Build & Run

Install
```
git clone https://github.com/CodCatDev/AmethystCore.git
cd AmethystCore
```

Build in release mode (GC ORC + No Debug)
```bash
nimble release
```

Build in debug (developer) mode (Standart GC + Debugging)
```bash
nimble dev
```
